# Contributing

For a bug, include reproducible steps, Chrome and flowix versions. Keep credentials and private content out of issues.

For code changes, run `npm test` and `npm run check`. Add a regression test for behavioral fixes. Keep permissions narrow, avoid remote code or telemetry, and check both popup languages and reduced-motion behavior for UI changes.

Describe the user-visible effect and validation in your pull request. Do not claim server-side access is guaranteed.
